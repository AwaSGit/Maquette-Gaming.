# Maquette Gaming

Maquette d'un site vitrine consacré au gaming et à l'e-sport, réalisée en HTML et CSS dans le cadre d'une formation avec Assofac en 2024.

## Présentation

Cette page présente plusieurs thèmes liés à l'univers du jeu vidéo :

- un en-tête avec une image de couverture, le nom du site, une navigation et un titre ;
- une introduction à l'e-sport ;
- une galerie d'images illustrant des événements ;
- des sections consacrées à la réalité virtuelle, au retrogaming et aux collectionneurs ;
- un pied de page avec des icônes de réseaux sociaux.

## Techniques utilisées

- HTML pour structurer le contenu d'une page statique ;
- CSS pour la mise en page, les couleurs, la typographie et le recadrage des images ;
- CSS Grid pour les galeries etgit push -u origin main les sections en colonnes ;
- Flexbox pour aligner les éléments de navigation et du pied de page ;
- des media queries pour adapter la mise en page aux petits écrans ;
- des images locales et des textes alternatifs (`alt`) pour les décrire.

Le projet ne nécessite ni installation ni dépendance : il s'agit d'une maquette front-end statique, sans JavaScript.

## Ouvrir le site

Ouvrir `Maquette-gaming.html` dans un navigateur. Pour prévisualiser le site depuis VS Code, ouvrir le dossier du projet et lancer **Live Server**.

## Fichiers du projet

- `Maquette-gaming.html` : structure et contenu de la page.
- `style (1).css` : mise en page, styles et adaptations aux écrans étroits.
- `images/` : images locales utilisées dans les différentes sections.

Les liens de navigation et de réseaux sociaux sont des liens de démonstration (`#`).
